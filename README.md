# Sales Performance Analytics Dashboard

## Project Overview
A retail sales analytics project built using Excel, PostgreSQL, SQL, and Power BI to analyze sales, profit, customer behavior, and regional performance.

## Tools Used
- Excel
- PostgreSQL
- SQL
- Power BI

## Features
- Data Cleaning
- SQL Analysis
- Interactive Power BI Dashboard
- Sales & Profit Analysis
- Customer Insights

## Dashboard Pages
- Executive Overview
- Sales Analysis
- Product & Customer Insights

## Key Insights
- Highest revenue market
- Top customers
- Best-selling products
- Monthly sales trends
